# Better Vanilla

Локальная подготовка новой карточки LANMinecraft. Целевая платформа: Minecraft 26.3, Fabric 0.20.1. В каталоге разместить карточку сразу после Better Than Wolves в группе «Мало модов». В `upstream-lock.json` закреплены размеры, SHA256 входных файлов, версии и точные совпадения 76 JAR с файлами авторов на Modrinth. Исходный архив пользователя и архив шейдеров сохранены отдельно.

Публичная поставка через GitHub Releases ожидает подтверждения прав на повторное размещение или поддерживаемого способа доставки с официальных источников. Среди модов есть компоненты с лицензией All Rights Reserved:

- [SubtleEffects-fabric-26.3-1.15.2.jar](https://modrinth.com/mod/subtle-effects/version/BMMtEpDv)
- [coolrain-1.4.0-26.3.jar](https://modrinth.com/mod/coolrain/version/K9R06E1l)
- [culturaldelights-26.3-0.19.8.4-refabricated.jar](https://modrinth.com/mod/cultural-delights/version/Tm0VloHM)
- [immersiveui-fabric-26.3-0.3.7+26.3.jar](https://modrinth.com/mod/immersive-ui/version/DSzQfCJh)
- [mcw-furniture-3.4.2-mc26.3fabric.jar](https://modrinth.com/mod/macaws-furniture/version/8Z6HSCVW)
- [shatterlib-fabric-0.7.0-beta.5+26.3.jar](https://modrinth.com/mod/shatterbyte-lib/version/yGChlg17)
- [xaerominimap-fabric-26.3-26.6.2.jar](https://modrinth.com/mod/xaeros-minimap/version/MfxfgXaO)
- [xaeroworldmap-fabric-26.3-1.47.2.jar](https://modrinth.com/mod/xaeros-world-map/version/VM8lNSSM)

Complementary Reimagined r5.9.3 допускает добавление через механизмы Modrinth или CurseForge. Пункт 1.2(d) лицензии в ZIP запрещает прямую загрузку файла. Для Bliss v2.1.2 право на повторное размещение точного архива требует подтверждения. MakeUp Ultra Fast 9.6 допускает распространение с атрибуцией и лицензией LGPL-3.0-or-later. Все три файла перечислены в lock.

`launcher/options-default.txt` задаёт штатный флаг пропуска сетевого предупреждения Minecraft 26.3. Пресет управления, фактический ModList, страницы библиотеки, native-приёмка и публичный выпуск ожидают подготовки. Публичный ID ещё не выделен.
